# PlaytonAI

Оригинальный веб-интерфейс Playton Corporation. Статический сайт без секретных ключей, совместимый с GitHub Pages.

Модели предоставляются через Puter.js. Войдите в собственную учётную запись Puter, выберите модель из актуального каталога и отправьте сообщение. Бесплатная квота ограничена; дальнейшее использование зависит от условий поставщика. История хранится локально в браузере. Внешние модели получают сообщения для обработки.

## Версия 2.0

- Markdown: выделение, заголовки, списки, таблицы, ссылки, цитаты и код. HTML от модели не выполняется.
- Вложения: текстовые файлы читаются в браузере, остальные отправляются в приватную файловую систему Puter при отправке сообщения. Поддержка форматов зависит от выбранной модели. Файлы остаются в Puter до удаления владельцем.
- Лимиты: фактический месячный остаток и расход из `puter.auth.getMonthlyUsage()`, цены и контекст выбранной модели из `puter.ai.listModels()`, стоимость запросов из серверных usage chunks. Показатели разных моделей не смешиваются; Puter не публикует оставшиеся внутренние RPM/TPM каждого провайдера.

## Версия 2.1

Восстановлен штатный процесс авторизации SDK для текстового чата и стандартное переключение доступных провайдеров той же модели. Настройка длины ответа (по умолчанию 2048 выходных токенов) позволяет снизить резервирование бюджета. Режим «Максимум модели» убирает пользовательский потолок длины, но серверные квоты остаются в силе. Fallback не обходит правила безопасности.

## OpenRouter Free

Страница `free.html` подключается к официальному API OpenRouter напрямую. Каталог содержит только бесплатные варианты с нулевой ценой, а также официальный `openrouter/free`. Авторизация выполняется с PKCE или с личным ключом, который хранится только в памяти вкладки. Дневной остаток читается из `GET /api/v1/key`. Вложения в свободном режиме: текст и изображения (только на поддерживающих их моделях). История бесплатного режима отдельная; изображения не сохраняются после перезагрузки.

## Guest

Главный адрес открывает `guest.html` — гостевой режим официального AI Horde. Не требует регистрации и личного API-ключа. Каталог живой, ответы обрабатываются в очереди добровольных серверов, длина и доступность ограничены правилами сети. Старый Puter находится на `puter.html`, OpenRouter — на `free.html`.

Чтобы опубликовать, загрузите файлы в корень репозитория, затем Settings → Pages → Deploy from a branch → main → / (root).
